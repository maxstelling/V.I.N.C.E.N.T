# Try the answer prompter

Use the updated V.I.N.C.E.N.T bookmark. The Safari School bookmark was updated on 13 November 2026. Other saved copies must have their full address replaced from the updated Setup page.

1. Open the review page for the same question set used in your game. You need an accessible public or user-owned review.
2. Select Blooket’s **Show all answers**.
3. Open the V.I.N.C.E.N.T bookmark. Select **Copy review answer key**. The panel shows how many questions were copied. If clipboard copying is blocked, copy the selected text box manually.
4. Open your active game tab and select the bookmark there.
5. Paste into **Answer key**, then select **Load key**.
6. Turn on **Highlight answers**. A matching answer gets a blue outline and a text hint in the panel. Select the answer yourself.

The key must belong to the same question-set version. The prompter checks the question text, picture, audio and all choices. It follows answer shuffling and question changes. If there is no exact match, it clears the previous hint and leaves every answer unmarked. It does not guess. Image-only choices and typed-answer questions are unsupported.

All tools start off. Auto-answer is disabled while a key is loaded. Stop All clears the current hints and timer. Clear key removes the key. Close and game navigation also clear it. Refresh data keeps the key for the same page and turns tools off. The key is kept only in panel memory; copied text remains on your clipboard until you replace it.

If hints do not appear, check that the copied set is the one used by the host and that the question has text choices. A changed game layout or different media URL may prevent a match. A disconnected or expired game must be rejoined first.
