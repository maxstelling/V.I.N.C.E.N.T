02 / OPEN

Run it inside the game

Open a Blooket game in the same browser, then select the saved bookmark. Start one tool at a time. Use Stop All to end automation.

Chromebook

In Chrome, show the bookmarks bar with Ctrl + Shift + B. Save the launcher and select it while the game tab is open. Personal and school devices may have different rules.

Windows 11

Use current Chrome or Edge. Show the bookmarks bar with Ctrl + Shift + B, save the launcher, then select it on the game tab. No Windows app is required.

If the bookmark does not open

Check the saved address starts with javascript:. Browser or page security can block it. On a school device, ask the administrator about allowed tools. There is no restriction bypass in this project.
